# Inkwell – Blog Application (Module 1: Frontend)

A responsive blog application interface built with **HTML, CSS and vanilla JavaScript** during my Codomax Digital Solutions internship.

## Pages
- `index.html` – Home with latest posts
- `login.html` – Login with validation
- `register.html` – Registration with validation
- `dashboard.html` – Your posts and stats (login required)
- `create-blog.html` – Create a blog post (login required)

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
Module 1 stores data in `localStorage` so the UI works without a server. Backend (Node/Express), database and JWT auth come in later modules.
